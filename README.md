# 🏥 CodeCare – Hospital Management System

A MERN Stack-based Hospital Management System developed as a collaborative team project during the **InternPro MERN Stack Development Internship** at **Faith Infotech Academy, Technopark**.

The project aims to simplify hospital operations through role-based access control and digital management of hospital activities.

> **Note:** This repository contains the collaborative work of the project team. The Admin module is fully implemented, while some other modules are partially implemented or under development.

---

# 📖 Project Overview

CodeCare is designed to improve hospital management by providing a centralized platform for managing patients, doctors, appointments, departments, laboratory services, and administrative tasks.

The application follows a role-based architecture where different users have access to different functionalities.

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/Anjanaps-17/CodeCare-Hospital-Management-System.git
```

## Navigate to the project

```bash
cd CodeCare-Hospital-Management-System
```

## Install Backend Dependencies

```bash
cd server
npm install
```

## Install Frontend Dependencies

```bash
cd ../client
npm install
```

---

# ▶️ Run the Project

### Start Backend

```bash
cd server
npm start
```

### Start Frontend

```bash
cd client
npm start
```
